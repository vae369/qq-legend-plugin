# 咕咕鸡传奇 · QQ 传奇游戏插件

> 一个把《传奇》游戏世界搬进 QQ 群的机器人插件：玩家不必打开客户端，在群聊或私聊里用文字指令即可创建角色、打怪爆装、合成神装、转生飞升、闯荡各大地图。

## 游戏简介

《咕咕鸡传奇》是一款具有东方魔幻色彩的网络角色扮演游戏，沿用传奇系列经典的**战士、魔法师、道士**三大职业体系。经验获取、打猎、采矿、PK、装备交易等核心玩法均在网络上实时发生，游戏世界包含昼夜更替、货币流通与物品贸易。

本插件是这套游戏世界的 **QQ 聊天端入口**。玩家在 QQ 群内发送指令，插件将其转换为游戏内的注册、移动、战斗、合成、交易等行为，并把结果以文字或图片形式回传到群里。

## 核心玩法

### 一、角色与成长

- **注册角色**：输入 `注册 名称,职业,性别` 创建角色，可选战士 / 法师 / 道士
- **等级属性**：1–100 级成长曲线，分别计算 HP/MP、攻魔道、物理防御、魔法防御、负重等属性
- **转生体系**：一转至五转，对应一转圣地、三转圣地、五转圣地等专属地图
- **状态查看**：`查看属性` / `查看装备` / `查看背包` / `查看技能` / `查看时装` / `查看状态`

### 二、装备、商铺与回收

- **装备回收**：`装备回收` / `一键回收`，支持装备勾选、批量勾选与取消勾选，回收结果以图片形式展示
- **系列装备浏览**：垃圾系列、沃玛系列、祖玛系列、赤月系列、永恒首饰 / 剑甲、毁灭首饰 / 剑甲、刑天 / 焚天 / 沧澜首饰、特殊物品
- **商铺系统**：奇珍榜、补给、强化、好友、限量、装饰六个分区

### 三、合成与锻造

- **宝石系统**：`合成宝石` 及 `升级宝石1` – `升级宝石15`
- **斗笠进阶**：普通 → 赤月 → 永恒 → 毁灭 → 沧天 → 灭世斗笠
- **三大神器**：天尊、法神、圣战神器合成
- **顶级追求**：灭世称号、灭世神技、首饰盒神技、永恒之力、高级宝石、神技提升

### 四、地图与冒险

| 阶段 | 代表地图 |
| --- | --- |
| 新手城镇 | 银杏小村、银杏山谷、边界小城、边界村、毒蛇山谷、比奇城、盟重土城 |
| 二大陆 | 天宫仙境、boss 之家 |
| 三大陆 | 沙漠荒原、虚空无尽、缥缈之巅、幽暗村庄 |
| 四大陆 | 大帝之城 |
| 五大陆 | 轮回之地、情缘仙人、仙庭战鼓 |
| 高阶副本 | 天帝陵墓、天帝炼狱、天帝足球场、天帝后花园、天帝奴隶场 |
| 特色区域 | 玛雅大厅、散人打宝、神秘地图、险恶 / 危险区域 |

传送方式包括 `城市传送` / `地图传送` / `传送员` / `向商店移动` / `回城`。

### 五、日常与活跃度

- **签到系统**：`签到` / `补签`，奖励元宝与经验，并累计活跃值
- **活跃值经济**：打怪、PK、击杀小 BOSS 分别扣除活跃值，按间隔时间恢复；另有每分钟回红 / 回蓝
- **福利领取**：起步礼包、赞助礼包、白嫖礼包、唯一赞助、赞助升级会员、元宝升级会员、领取充值、路费、宣传码
- **公益玩法**：开启公益捐献 / 公益捐献、我要成佛、我佛慈悲

### 六、战斗与交互

- `PK`、`卖物品`、`卖肉`、`万事通`、`老兵`、`战斗记录`（默认保留 5 回合）
- 支持开启 / 关闭发送动图，怪物掉落与极品提示（文字与元素极品几率可配置）

### 七、管理与调试

- **GM 指令**：`GM功能`、`屏蔽本群`、`清除注册信息`、`屏幕监视`、`自动挂机`
- **配套工具窗口**：游戏数据编辑（职业等级属性 / 技能 / 怪物 / 物品 / 地图爆率）、NPC 脚本测试、魔法测试、图片处理与小地图编辑

## 技术实现

| 项目 | 说明 |
| --- | --- |
| 运行平台 | .NET Framework 4.7.2，Windows |
| 界面 | WinForms（`FormMain` 为主控制台，`MirTest` / `MirNpcTest` / `FrmMagicTest` 等为测试工具） |
| 框架接入 | 纯白铃框架插件导出入口（`get_plugin_info` / `on_enable` / `on_message` 等 cdecl 导出），基于 DllExport |
| QQ 接口 | `MingQQAPI.DLL`（Api.cs 中的 `DllImport` 封装） |
| 消息模型 | `MessageInfo` 统一入口，按群聊 / 频道 / 私聊 / 频道私聊分发；支持 equals / startswith / endswith / contains / regex / event 六类指令规则 |
| 图像处理 | Magick.NET.Q16 13.10.0，用于装备截图、角色图片与动图生成 |
| 文件打包 | Fody.Costura 合并依赖 |
| 配置 | `Config/传奇/config.ini`（GBK 编码），包含超级管理员、签到元宝 / 经验、活跃值规则、极品几率、礼包码等 |

## 目录结构

```
QQ插件/
├── QQ插件.sln                # 解决方案
└── 传奇/
    ├── 传奇.csproj           # 主工程（程序集名：传奇.MQ.exe）
    ├── Api.cs                # QQ 框架原生接口封装
    ├── QQMain.cs             # 游戏指令主分发器
    ├── FormMain.cs           # 管理控制台
    ├── index.html            # 游戏指令说明文档
    ├── Qiancao/              # 框架适配层（插件导出、SDK、指令规则表）
    ├── Service/              # 业务 API（角色、装备、商铺、地图、怪物、NPC、奖励）
    ├── Models/               # 数据模型（角色、物品、怪物、技能、地图、爆率）
    ├── core/                 # 通用工具（INI 读写、文本格式化、文件辅助）
    └── Properties/           # 程序集信息与资源
```

## 构建

1. 使用 Visual Studio 打开 `QQ插件.sln`
2. 还原 `packages.config` 中的 NuGet 依赖（DllExport 1.5.2、Fody 6.9.3、Magick.NET 13.10.0）
3. 编译生成 `传奇.MQ.exe`

> 插件运行依赖外部 QQ 框架提供的 `MingQQAPI.DLL` 与纯白铃框架环境；游戏服务端数据文件需按 `Config/传奇/` 目录结构放置。
